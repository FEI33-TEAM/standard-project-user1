# 🚗 АвтоМито — Калькулятор розмитнення авто

Навчальний проект на **React + Vite** для вивчення основ фронтенду.
Тема проекту — розрахунок митних платежів при ввезенні автомобіля в Україну.

## Структура проекту

```
src/
├── components/          # Перевикористовувані компоненти
│   ├── Header.jsx       # Шапка сайту з навігацією
│   ├── Footer.jsx       # Підвал сайту
│   └── FormGroup.jsx    # Компонент поля форми
├── pages/               # Сторінки застосунку
│   ├── HomePage.jsx     # Головна сторінка
│   ├── CustomsDutyPage.jsx  # Калькулятор ввізного мита
│   ├── ExciseTaxPage.jsx    # Калькулятор акцизного податку
│   ├── TotalCostPage.jsx    # Повний розрахунок
│   ├── AboutPage.jsx    # Про сервіс (заглушка)
│   ├── FaqPage.jsx      # FAQ (заглушка)
│   └── NotFoundPage.jsx # Сторінка 404
├── App.jsx              # Кореневий компонент + роутинг
├── App.css              # Стилі компонентів
├── index.css            # Глобальні стилі
└── main.jsx             # Точка входу React
```

## Технології

| Технологія | Версія | Навіщо |
|---|---|---|
| React | 19 | UI-компоненти |
| React Router | 7 | Навігація між сторінками |
| Vite | 8 | Збірка та dev-сервер |

## Запуск

```bash
npm install
npm run dev
```

Відкрий http://localhost:5173

## Міні-задачі для початківців 🎯

1. **Легко**: Додай своє питання в масив `faqs` у `FaqPage.jsx`
2. **Легко**: Зміни кольори у `:root` в `index.css`
3. **Середньо**: Додай поле «Марка авто» до форми в `TotalCostPage.jsx`
4. **Середньо**: Зроби щоб кнопка «Розрахувати» була неактивна до заповнення полів
5. **Середньо**: Додай конвертор валют на окрему сторінку (`/converter`)
6. **Важко**: Збережи останній розрахунок у `localStorage`
7. **Важко**: Додай графік (наприклад через `recharts`) для візуалізації розбивки платежів
